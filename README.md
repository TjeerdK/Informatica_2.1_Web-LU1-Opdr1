# Filmverhuur Applicatie

Dit project is een webapplicatie voor het beheren van een filmverhuursysteem. Medewerkers kunnen inloggen, films toevoegen, bewerken, verwijderen en zoeken in het filmaanbod. De applicatie is gebouwd met Node.js, Express en Pug.

## Functionaliteit
- Inloggen en uitloggen voor medewerkers
- CRUD (Create, Read, Update, Delete) voor films
- Zoeken en filteren op filmtitel
- Duidelijke foutmeldingen bij verkeerde inlog of invoer
- Overzicht van alle beschikbare films
